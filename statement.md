# Problem Statement

The project aims to develop a simple Student Grades Management System that allows users to store and manage student marks while automatically calculating percentages and grades.

The system demonstrates Python concepts such as dictionaries, functions, conditional statements, loops, user input, and basic data management.

# Scope of the Project

The project includes:

* Adding student records.
* Updating student marks.
* Removing student records.
* Viewing student information.
* Calculating average percentage.
* Automatically assigning grades.
* Menu-based command-line interaction.

# Target Users

* Students learning Python
* Programming beginners
* Teachers or learners practicing basic student record management

# High-Level Features

1. **Add Student** – Stores a student's name and marks.
2. **Update Student** – Updates marks for an existing student.
3. **Remove Student** – Deletes a student record.
4. **View Students** – Displays stored student records.
5. **Percentage Calculation** – Calculates the average of three subjects.
6. **Grade Assignment** – Assigns a grade based on percentage.
7. **Menu System** – Provides simple options for managing records.
